# Task UX-3: Static HTML Report Export

## Objective
Allow users to export their current Analytics view (pivot table, charts, AI insights) as a **self-contained HTML file** that anyone can open in a browser — without needing LocalMind installed. This serves as a viral growth mechanic: recipients see the report and discover LocalMind.

## Implementation Details

### 1. Export Button
- Add an "Export Report" button in the Analytics workspace toolbar.
- Opens a modal to configure the export:
  - **Title:** editable text field (default: table name + timestamp).
  - **Include options:** checkboxes for Pivot Table, Chart, AI Insight, Generated SQL, Raw Data (first 100 rows).
  - **Theme:** Light / Dark.

### 2. HTML Template Generator
Create `src/lib/services/ReportExporter.ts`:

- Generates a single `.html` file with:
  - **Inlined CSS** — no external dependencies.
  - **Inlined chart** — ECharts renders to a `<canvas>`, export as a base64-encoded PNG embedded via `<img>`.
  - **Pivot table** — rendered as a styled `<table>` with the same formatting as the app.
  - **AI insight** — rendered as a styled blockquote.
  - **Generated SQL** — rendered in a `<pre><code>` block.
  - **Footer** — "Generated by LocalMind — privacy-first local analytics. Try it at localmind.dev"

### 3. File Download
- Use `URL.createObjectURL(new Blob([html], { type: 'text/html' }))` to trigger a browser download.
- Filename: `LocalMind_Report_<title>_<date>.html`.

### 4. Branding & Viral Loop
- The report footer includes a subtle "Powered by LocalMind" link.
- The HTML file is fully self-contained — no external requests, no tracking, no analytics.
- This maintains the privacy promise even in the exported artifact.

## Acceptance Criteria
- [ ] "Export Report" button visible in Analytics workspace.
- [ ] Export modal allows selecting which sections to include.
- [ ] Generated HTML file opens correctly in Chrome, Firefox, Safari, Edge.
- [ ] Charts are embedded as base64 PNG images (not interactive, but viewable).
- [ ] Pivot table renders with proper formatting and totals row.
- [ ] File is fully self-contained (no external CSS/JS/image requests).
- [ ] Footer includes "Generated by LocalMind" branding with link.
- [ ] File size is reasonable (< 2MB for a typical report).
